# garmin-zig

A client for the Garmin Connect API. There is no public API for personal data, so the client signs in through Garmin's web SSO, with multi-factor authentication, and caches the resulting OAuth tokens. The library covers activities, wellness, body composition, gear, goals, and training metrics, and a command-line tool prints them as JSON and downloads the original FIT files. The client is large and owns every buffer it uses, so a caller creates it once, initializes it in place, and drives it from one thread. The client allocates nothing afterwards, and each response body it returns is borrowed from its storage until the next request. A fake transport answers from scripted responses, so the tests and the example in `examples/activities.zig` run without a network.
